01

Project Overview

From fractional relaxations to guaranteed integer optima — understanding the mechanics of Branch & Bound.

🔢

What is Integer Programming?

Integer programming (IP) is a type of optimization where some or all decision variables must be whole numbers — no fractions allowed. Think of deciding how many full trucks to send or how many whole units to produce. Standard linear programming ignores this constraint, which leads to impractical answers like "send 3.7 trucks."

🧩

Why Do Relaxations Give Fractions?

When we drop the "integers only" rule, we solve a simpler version called the LP relaxation. The mathematics becomes continuous, so the solver can freely choose any value — including 2.6 or 0.4. The LP relaxation gives an upper bound on the best possible integer answer, but it's not a valid solution by itself.

🌿

Why Branch & Bound?

Checking every integer combination is computationally explosive — even small problems have billions of possibilities. Branch & Bound is smarter: it breaks the problem into sub-problems (branching) while using math to prove that entire groups of solutions can't possibly beat the best answer found so far (bounding). This way, most of the search space is never explored.

🌲

How Branching Works

When a fractional variable appears — say x₁ = 2.3 — we create two child problems: one where x₁ ≤ 2 and one where x₁ ≥ 3. Each branch restricts the feasible region. We keep splitting until every open node either yields integer values or proves hopeless. This systematic splitting forms a decision tree.

📊

How Bounding Works

At each node, we solve the LP relaxation to get an upper bound on the best integer solution attainable in that subtree. If a node's bound is already worse than the best integer solution we've found, exploring it further is pointless. Bounding turns the search from "check everything" to "check only what matters."

✂️

Fathoming — Pruning Dead Ends

A node is fathomed (pruned) when: (1) it's infeasible — no solution exists; (2) it's already integer-valued — it's a candidate solution; or (3) its LP bound is no better than the current best integer solution. Fathomed nodes are closed forever, dramatically reducing the tree size.

BB

Best Bound

The highest LP relaxation value across all active (open) nodes. This is the theoretical ceiling — no integer solution lurking undiscovered can beat it.

BI

Best Incumbent

The best integer-feasible solution found so far. It improves over time as better integer nodes are discovered. We keep this as our running "best answer."

OG

Optimality Gap

OG = (BB − BI) / BB × 100%. It measures how far from optimal we might still be. When OG reaches 0%, the algorithm terminates with a guaranteed optimal solution.

What Did I Learn?

Knowledge built, skills sharpened, and insights that changed how I think about optimization.

Knowledge

Concepts Understood

Integer Programming Branch & Bound Branching Bounding Fathoming Optimality Gap
I learned that Integer Programming isn't just a stricter version of linear programming — it's a fundamentally harder problem class. The B&B algorithm is a structured workaround: instead of solving the hard problem directly, it decomposes it into solvable sub-problems and discards hopeless regions using mathematical bounds.
Skills

Capabilities Developed

Optimization Reasoning Tree Analysis Algorithm Visualization Systematic Problem Solving
Building this explorer forced me to trace through each step manually first, which deepened my understanding far beyond reading alone. I can now trace a Branch & Bound tree by hand, identify which nodes to fathom, and interpret the optimality gap as a live convergence signal.
Reflection

How My Thinking Shifted

Efficiency Over Exhaustion Smart Search
The biggest insight: solving every possible solution is almost always impractical. Branch & Bound succeeds by eliminating regions that cannot improve the answer. The order in which nodes are explored can massively affect runtime efficiency. Good optimization is often more about reducing search effort than checking everything — a lesson that extends well beyond math.
