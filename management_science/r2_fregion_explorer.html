Linear Programming Foundations

📐 What is Linear Programming?

Linear Programming (LP) optimizes a linear objective function subject to linear constraints. A feasible region is the set of all points satisfying every constraint — typically a convex polygon. Constraints define resource limits, demand requirements, or policy bounds.

Why optimal solutions occur at corner points: because the objective function is linear, its maximum over a convex polygon must lie at an extreme point (unless parallel to an edge, then multiple optima). Managers use LP for resource allocation, production planning, and logistics.

📌 Solution Types

  • ✓ Feasible solution – satisfies all constraints
  • ⭐ Optimal solution – best objective value among feasible
  • 🚫 Infeasible – no common intersection (contradiction)
  • ∞ Unbounded – region extends infinitely, objective can grow without bound
  • 🔄 Multiple optimal – objective parallel to binding edge

Real-world decisions require recognizing which case applies: managers leverage sensitivity analysis and constraint refinement.
