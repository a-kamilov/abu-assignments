Fundamentals

Core Concepts

Six interconnected ideas that together power one of the most important algorithms in decision science.

⎇
Branching
Divide a complex problem into smaller, more manageable subproblems by fixing a decision variable's value.
x₁ = 0 → left branch
x₁ = 1 → right branch
⌃
Bounding
Compute an optimistic estimate of the best solution achievable from any given node by relaxing integer constraints.
LP relaxation bound: 47.3
Must round down to: 47
◈
Best Bound
The most optimistic objective value possible given all nodes remaining in the search tree — a ceiling on the final answer.
BB = max({bound of
all active nodes})
★
Best Incumbent
The best integer-feasible solution found so far during the search — the current champion that new candidates must beat.
z* = 42 (current best
integer solution)
△
Optimality Gap
The difference between the Best Bound and Best Incumbent. When the gap reaches zero, optimality is proven.
Gap = BB − z* = 5.3
→ 0 means optimal
✂
Fathoming
Prune (discard) a node when its bound cannot improve the best incumbent — eliminating entire subtrees at once.
bound ≤ z* → prune
no better solution exists
The algorithm

How Branch & Bound Works

01

Start from the Root Node

The original problem, untouched, becomes the root. All variables are free. The entire feasible region is open for exploration.

Initialization
02

Relax the Problem

At each node, solve a relaxed version — allowing fractional values. This gives an upper bound on what any integer solution under this node can achieve.

LP Relaxation
03

Branch into Subproblems

Select a fractional variable from the relaxed solution and create two child nodes — one with the variable rounded down, one rounded up. Each child inherits parent constraints plus the new bound.

Divide & Conquer
04

Prune Unpromising Branches

A node is fathomed when: its bound is no better than the current best solution, it is infeasible, or its relaxation yields an integer solution. Entire subtrees vanish with a single comparison.

Pruning
05

Reach the Optimal Solution

When the list of active nodes empties, the best incumbent is proven globally optimal. The optimality gap has closed to zero — not just "good enough" but certifiably best.

Convergence

The Example Problem

We want to maximize a profit objective subject to two resource constraints, where both decision variables must be non-negative integers (you can't produce half a unit).

Objective
Maximize: 5x₁ + 4x₂
Constraints
6x₁ + 4x₂ ≤ 24
x₁ + 2x₂ ≤ 6
x₁, x₂ ≥ 0, integer

The LP relaxation (ignoring the integer requirement) gives x₁ = 3, x₂ = 1.5 with objective value z = 21. Since x₂ is fractional, we cannot accept this — we must branch on x₂. Each step below reveals exactly what the algorithm does, in order. Nothing already shown ever changes.

Branching Strategies

Different traversal strategies navigate the tree in different ways, trading off memory, speed, and solution quality.

Backtracking
Depth First
Dive deep into one branch before backtracking. Uses minimal memory. Quickly finds feasible solutions but may spend time in poor subtrees.
Jumptracking
Best First
Always expand the node with the best bound, regardless of depth. Finds optimal solutions faster but requires more memory to track all active nodes.

Summary

Key Takeaways

01
Branch & Bound avoids exhaustive search by intelligently dividing problems and eliminating entire regions of the solution space.
02
Bounding estimates the best possible outcome from any node using a relaxed problem — giving a provably optimistic ceiling.
03
Pruning removes unnecessary work — when a branch cannot beat the current best solution, the entire subtree is discarded.
04
Optimality is proven when the gap closes — unlike heuristics, Branch & Bound certifies that no better solution exists.
05
Intelligent search enables large-scale optimization — problems that would take millennia by brute force become solvable in seconds with Branch & Bound.
